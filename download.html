Quick Setup Guide

1

Download & Install the Agent

Download the MSI installer above. For mass deployment, use msiexec /i OrgTracesAgent.msi /quiet APIKEY=your_key ORGID=your_org_id

2

Configure Your Organization

Log into the Manager Dashboard and set up departments, monitoring policies, and wellness intervals per team.

3

Start Monitoring

Once agents connect, you'll see real-time activity, screenshots, AI detection alerts, and compliance reports in your dashboard.

System Requirements

✓ Windows 10/11 (64-bit)
✓ 4 GB RAM minimum
✓ 200 MB disk space
✓ .NET 6.0 Runtime
✓ Internet connection (or on-prem server)
✓ Admin rights for install
✓ Camera (optional, for AI detection)
✓ CPU: 1% average usage
